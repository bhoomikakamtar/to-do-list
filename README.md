# Flask To-Do App

## Overview

Flask To-Do App is a simple task management application built using Flask and MongoDB. It allows users to create, manage, update, and delete tasks through a clean web interface. The project demonstrates the integration of a Python web framework with a NoSQL database.

## Features

* Add new tasks
* View all tasks
* Update existing tasks
* Delete tasks
* MongoDB database integration
* Simple and responsive user interface

## Technologies Used

* Python
* Flask
* MongoDB
* HTML
* CSS
* Git & GitHub

## Project Structure

├── app.py
├── requirements.txt
├── .github/workflows
├── templates/
├── flask_todo/static/
├── .env
└── README.md

## Installation

1. Clone the repository.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
3. Configure MongoDB connection in the `.env` file.
4. Run the application:

   ```bash
   python app.py
   ```
5. Open the application in your browser.
